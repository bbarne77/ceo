# bbarne77 portfolio — version 2

Обновлённый персональный сайт с акцентом на портрет и личный бренд.

## Перед публикацией
1. Открой `config.js`.
2. Вставь Telegram-ссылку в `telegram`.
3. Заполни ссылки на ZisVPN и iPAWSign. iPAWORLD уже ведёт на https://ipaworld.ru/.
4. Фотография уже лежит в `assets/portrait.jpg`.

## Запуск
Открой `index.html` в браузере или запусти локально:
```bash
python -m http.server 8000
```
Открой http://localhost:8000.

## Публикация
Статический сайт: сборка не нужна.
- Cloudflare Pages: Direct Upload папки проекта, build command пустой, output directory `/`.
- GitHub Pages: загрузи содержимое в корень репозитория и включи Pages для нужной ветки.

## Что добавлено
- Большой персональный hero с портретом.
- Кинематографичная загрузка и анимация появления секций.
- Анимированные орбиты, бегущая строка, световой эффект курсора.
- Магнитные кнопки на компьютере.
- Интерактивные проекты с модальными окнами.
- Адаптация под мобильные устройства и настройку reduced motion.
